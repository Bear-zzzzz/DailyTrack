核对日期：2026-11-16。来源限于正式规范、官方文档/仓库、官方工程文章与公开标准草案；不把论坛问答当作协议依据。正文引用的来源标记在下文逐条对应，原题定位与技术答案来源是两个维度。

## 版本与证据的使用边界

- MCP 概览入口当前指向 2026-07-28 文档；tools/安全示例明确引用 2025-11-25 版本。实际部署按双方兼容版本，不混用初始化与字段规则。
- OpenCode 当前 API 与 V1 Server 文档分别列出，Pi 与 Superpowers 按本次读取的 README 描述，不承诺插件、默认功能或命令永久不变。
- Go 1.14/1.25 用于解释历史实现变化；GC 内部实现与部署默认值应按实际工具链核实。Python 以 3.14 文档区分普通和 free-threaded CPython；不将这类实现行为说成所有 Python 的语言保证。
- MySQL 结论主要限定 InnoDB 8.4；Hive 需要具体执行引擎和计划。Redis 持久化/线程模型要按版本、配置和故障模型回答。
- Kafka 基础说明引用 4.1，重平衡参考 4.2 文档解释自 4.0 起的演进；不把经典与新协议实现混在一起。
- C++ 公共草案是持续更新的工作文档，ABI 不是语言布局保证；atomic shared_ptr 的版本条件在正文标明。
- Microsoft 的 outbox 示例以 Cosmos DB 为例；本文推广到关系型数据库的同事务记录/投递设计是工程建议，不声称能直接复制示例。
- 原理的适用边界、失败条件和语义比背某个默认参数更重要。来源校验不等于对你的生产环境做过测试。

## 算法、公式和项目数据

- 条件概率、三数之和与全排列按正文给定假设推导。令牌桶的补充与扣减公式是通用算法说明，具体实现要验证时钟和原子性。
- 公历月份概率使用 UTC 遍历 2000—2399 年：4800 个月，周一开头 684 个，结果 57/400；不是原面经中已给出的采样条件。
- 提效指标公式是本文建议口径，不能直接作为你的项目数据；所有实际百分比、QPS、薪资和职责应有个人证据。
- 原始资料完整性、题库统计与本次答案文档的结构校验分开记录。
