**【项目一】车辆软件问题智能诊断 Agent**
*技术栈：Python / FastAPI / LangChain / OpenAI 兼容 LLM / SQLite / Hybrid Retrieval / YAML 配置驱动*

面向车辆软件问题排查场景，构建基于 LLM 自主规划的 ReAct Agent 系统。系统接收工单输入（VIN、故障现象、发生时间）后，自动采集车云日志、检索代码仓库、进行日志与代码关联分析，输出**证据-grounded 的结构化根因报告**，将传统人工排查升级为 Agent 自主规划 + 工具自动执行 + 证据自动关联 + 结论可追溯的智能诊断流程。

- **三层插件化 Agent 架构**：设计 Domain / Skill / Command-Tool 三层插件化架构，全部通过声明式 YAML 配置描述能力边界，新增业务能力无需改动引擎核心代码，支持多领域 / 多场景 / 多租户扩展。
- **ReAct Runtime + 多层护栏 + 工具权限网关**：实现完整 Reason→Act→Observe 闭环引擎；Runtime 护栏覆盖 Repetition Detection / Periodic Reflection / Turn-Budget Awareness / Self-Correction（error_code 回灌）/ 软降级；通过 planner.approve + allowed_tool_names 白名单 + 路径/biz_type 白名单 + 多级 Filter 拦截工具调用，权限拒绝结构化回灌 Agent 上下文。
- **Hybrid RAG + 经验记忆 + Trace / Resume**：BM25 + 向量混合检索 + Query Rewriting + Metadata Filtering + Top-K Rerank，历史结论沉淀为可复用经验，新工单自动召回；append-only investigation_events 真相源 + TraceRecorder 关键事件 + call_id/reply_to 关联 + Checkpoint 快照 + Resume / Replay / failed_replay / initial_state 注入。
